# Chapter title band

| | |
|---|---|
| **Group** | 2. Pacing / 8. Type |
| **What it does for the story** | A full-width band with the chapter name in big display type (sometimes on a pattern) marks a clear break and a breath before the next part. |
| **Seen on** | Nature brain ("Special recipe", "Making connections" on a textured navy band, `shots/nature-brain-1280-039.jpg`); The Pudding onions (puffy 3D words "POINT BELOW", "EXPLORE", `shots/pudding-onions-1280-008.jpg`); Man City ("Footballing firsts" navy band, `shots/mancity-women-375-017.jpg`); BBC Olympic ("ATHLETICS" heading on its own screen, `shots/bbc-olympic-1280-018.jpg`). **Seen on 4.** |
| **Phone version** | Same band, type scaled down; on all four sites it takes a third to a half of a phone screen. |
| **How to build (vanilla)** | `<h2>` inside a full-bleed `<section class="band">`, display font at `clamp(2.5rem, 9vw, 6rem)`; optional subtle SVG pattern behind. A one-off fade on enter. |
| **Cost / risks** | Very low. Over-use makes the page feel like slides. |
| **Reduced motion** | Static. |
| **Use when** | Every hub guide chapter. BTS: Montserrat display on the dark theme, wave or wake pattern behind. |
| **Don't use when** | Short sections (under about 2 phone screens). |
