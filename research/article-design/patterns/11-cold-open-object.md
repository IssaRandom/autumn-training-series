# Cold open on one object

| | |
|---|---|
| **Group** | 1. Openings |
| **What it does for the story** | The first screen is one object on a quiet background plus the title and a scroll cue. Says what the piece is about without copy. |
| **Seen on** | ESPN F1 (top-down 1950 car, `shots/espn-1280-000.jpg`). LeBron opens with a busier video landing instead. **Seen on 1.** |
| **Phone version** | Same, title over the object. |
| **How to build (vanilla)** | Plain hero; optional slow drift with CSS keyframes, stopped under reduced motion. |
| **Cost / risks** | Low. Needs one great cut-out photo. |
| **Reduced motion** | Still image. |
| **Use when** | Photo offshoots ("the ILCA mast"), kit guides. |
| **Don't use when** | News/event previews (lead with the facts). |
