# Boxed aside ("Did you know?")

| | |
|---|---|
| **Group** | 2. Pacing / 5. Explaining things |
| **What it does for the story** | A small framed box with a side fact or a simpler explanation. It breaks a text run and lets skimmers pick up the key point. |
| **Seen on** | The Pudding onions ("Simplifying the problem" box with a mini diagram, `shots/pudding-onions-1280-010.jpg`); BBC Olympic ("Did you know?" boxes on navy, `shots/bbc-olympic-375-018.jpg`); Nature fusion ("Spherical vice" box with its own diagram, `shots/nature-fusion-375-012.jpg`). **Seen on 3.** |
| **Phone version** | Full column width with a tinted background on all three. Pudding sets it beside the text on desktop and inline on phones. |
| **How to build (vanilla)** | `<aside>` with a border or tint; on wide screens a CSS grid side column; inline under about 700px. |
| **Cost / risks** | Very low. Must be skippable: never put the only copy of a key fact in it. |
| **Reduced motion** | No motion needed. |
| **Use when** | Kai's tips ("Coach's note"), rule clarifications, a quick "what is a PRO?". |
| **Don't use when** | More than one per phone screen. |
