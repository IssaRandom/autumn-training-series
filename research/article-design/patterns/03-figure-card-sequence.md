# Figure cards ("Fig N")

| | |
|---|---|
| **Group** | 5. Explaining things |
| **What it does for the story** | One fact per card: label in big display type, one picture, a short paragraph, a figure number. The numbering makes a list feel like a set. |
| **Seen on** | ESPN F1 2026 rules (Body length, Total weight, …; `shots/espn-1280-062.jpg`, `-078.jpg`); LeBron stat cards (`shots/lebron-1280-013.jpg`). America's Cup "The boats" (AC40 photo with crew, length and top-speed numbers laid over it, https://www.americascup.com/the-boats, `shots/ac-boats-375-006.jpg`). **Seen on 3.** |
| **Phone version** | One card per screen, stacked. Works well. |
| **How to build (vanilla)** | Plain CSS grid card; reveal each with a short fade/slide on enter (IntersectionObserver adds a class). Optional sticky chapter label above. |
| **Cost / risks** | Low. |
| **Reduced motion** | Cards just appear, no motion. |
| **Use when** | Rig settings, kit lists, boat parts, the steps of a how-to (photo offshoots). |
| **Don't use when** | Flowing argument or story text. |
